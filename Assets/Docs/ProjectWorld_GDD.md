# Project World - Game Design Document (Working Draft)

## Vision

A fantasy grand strategy game that combines: - Civilization-style
exploration and expansion - Tactical hex-grid combat - Distinct fantasy
races - Procedurally generated worlds

## Core Gameplay Loop

1.  Generate a procedural world.
2.  Spawn each player with:
    -   Settler
    -   Scout
3.  Explore the world.
4.  Found a Village.
5.  Gather resources.
6.  Recruit units.
7.  Expand, conquer, or capture enemy Villages.

## Core Rules

-   One settlement type: Village.
-   Settlers found Villages.
-   Villages can be captured.
-   Villages must be at least 3 hexes apart.
-   Villages cannot be founded on Mountains or Water.
